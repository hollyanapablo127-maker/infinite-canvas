# 无限画布

Wan 3.0 北京区域的多用户视频创作工作台。React Flow 画布、NestJS 服务、PostgreSQL、私有资产和持久任务队列。

## 本机运行

要求 Node.js 20.19+、FFmpeg/FFprobe；依赖使用国内 npm 镜像。

```powershell
npm install
npm run build
npm start
```

打开 http://127.0.0.1:4010，界面与 API 由同一个本地服务提供。首次访问创建管理员，无预置账号密码。本地未设置 DATABASE_URL 时使用 data/ 中的 PGlite 数据库，不向外发起模拟调用。注册默认关闭。

开发时可运行 `npm run dev`，前端 http://localhost:5173，API http://127.0.0.1:4010；先停止已有服务避免端口冲突。页面会按登录结果识别身份，无需选择角色。

本地数据、上传文件、密钥加密根密钥保存在忽略提交的 data/。不要删除 data/.secret，否则已有渠道凭据无法解密。已有数据库与密钥必须一并备份。

## 上线配置

1. 复制 `.env.example` 为 `.env` 并填写 PostgreSQL、APP_SECRET、HTTPS 域名。生产必须 PostgreSQL；数据库队列无需额外 Redis。
2. 配置北京 OSS 的 private Bucket、专用 RAM 身份与最小权限。或设置可公开 HTTPS 访问的 PUBLIC_BASE_URL，供阿里服务读取站内短期签名素材。纯 localhost 无法传送素材给模型。
3. 配置 SMTP 邮件服务，再启用注册邮箱验证。未验证邮箱不允许通过邮件重置密码。
4. `npm run build` 后 `npm start`。生产经 Nginx HTTPS 反向代理同一站点，不直接暴露后端端口。
5. 初始化管理员后，在百炼 API 页面配置北京 WorkspaceId、API Key、主账号分组和成本倍率。初始所有用户余额为 0，由管理员人工充值。

渠道成本 = 用户本次实际消费 × 提交时的成本倍率。官方活动价仅为参考，本站六档售价初始为官方原价。用户接口不返回渠道成本。

## 使用

创建画布，加入生成节点，选择模式、输入素材及提示词，获取报价并确认提交。可在画布或使用记录跟踪任务。生成节点之间的连接代表视频依赖；批次显式确认预算后逐项执行，前序失败或价格变化即停止后续提交。已运行任务不会重复提交。

上传素材、生成结果独立保留 30 天；派生文件沿用原素材到期日。7/3/1 天发送站内提醒。删除进入回收站，原到期日前可恢复，仍计入容量。生成历史、提示词和账单保留。资产可批量打包，单包不超过 500MB，下载包最长 24 小时。

视频延长仅 adaptive。计费秒数为输入视频总时长 + 完整输出时长，最大 30 秒。智能时长预占 30 秒。只可取消站内 QUEUED 或上游 PENDING 任务。网络中断导致提交结果不明确时进入待核实，管理员核实后处理，不自动再生成。
