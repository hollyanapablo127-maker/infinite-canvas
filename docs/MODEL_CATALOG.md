# 模型目录、专属倍率与提示词优化

## 管理员配置

1. 进入「渠道管理」添加上游。视频/图片仍使用原有接入协议；「语言」渠道填写 OpenAI 兼容的 Base URL 与 API Key。
2. 语言渠道可点击「自动获取模型」读取 `/v1/models`，也可手动添加模型 ID。左侧为本站模型 ID，右侧映射为真正发送给上游的模型 ID。编辑时密钥留空保留原值，响应与审计不返回密钥。
3. 「测试连接」会发送真实的 SSE 请求，默认消息为 `Hi`，可选择模型与思考强度，并查看真实返回内容。此操作可能产生上游费用。
4. 进入「模型定价 → 添加模型」，输入任意符合格式的模型 ID、名称与说明，选择视频/图片/语言/语音类型，关联相应渠道并确认上游模型映射。渠道中的映射可作为默认值，模型目录里明确保存的映射决定实际请求。
5. 视频和图片模型需要选择现有兼容协议，其参数与能力以该协议为准；新建时配置初始价格，之后可独立增删改价格档位。新的模型 ID 可以使用不同上游名称，不再限于补齐内置档位。
6. 语言模型按百万输入/输出 token 计价。语音目录支持百万 token、百万字符、秒或次四种单位；当前画布尚无语音生成节点。
7. 删除模型会下架当前目录和价格，历史任务、价格外键与协议资料保留。同一 ID 重新发布时不能改变原类型或协议。

## 用户专属倍率

在「用户管理」点击用户行的「专属倍率」。`1` 是本站原价，`0.8` 是本站售价的八折，`0` 为免费。范围为 0–1。

倍率同时用于广场价格、视频/图片报价、预算冻结、工作流和语言优化。已提交任务保存独立价格快照，后续调价和倍率变更不会改动历史任务。未提交报价会在价格或倍率变化时要求重新获取。渠道成本使用本站原始价格及渠道成本倍率计算，不与用户折扣混用。

## 提示词优化

在文本节点上勾选「AI智能优化提示词」，在右侧选语言模型与思考强度，点击「开始优化」。服务发送内置的提示词编辑系统指令与用户原始文本，使用 OpenAI 兼容的 `/v1/chat/completions` SSE 流式请求。

优化前、优化后的内容保存在临时对比草稿里。生成完成或停止后可以编辑两侧内容；点击保留某一侧才会一次性写入文本节点。关闭窗口、删除节点或离开画布会停止请求，原文不会被流式内容提前覆盖。

语言请求使用唯一请求键防止重复扣费。先以输入文本上限及 2048 个输出 token 预占预算，正常完成按上游 usage 结算；上游缺少 usage 时按 UTF-8 文本字节上界估算并明确标记，费用不超过预占金额。中断保留已收到文本并释放差额；上游拒绝且未返回内容时释放全部预算。异常终止的未完成预占由每分钟运行的恢复任务回收（记录超过十分钟时）。

## 界面与验证

模型广场侧栏按渠道及四种类型筛选，带搜索和固定分页；点击模型显示独立的价格详情和当前用户实付价格。

全站使用统一深色液态玻璃材质、鼠标随动光晕、点击涟漪与按压反馈。触屏关闭鼠标跟随，系统选择「减少动态效果」时关闭持续动效；画布节点避免叠加重度模糊。

测试使用隔离数据库与本地 HTTP SSE 上游，不向真实付费模型自动发送请求。真实渠道的兼容性请在管理页使用「测试连接」查看实际响应。
