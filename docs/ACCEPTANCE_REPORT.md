## 已验证流程

- 首次管理员创建、关闭注册、统一登录、管理员与个人双分区、普通用户权限隔离。
- 官方原价六档、精确金额、幂等充值、退款限额、余额与流水一致、重复提交与取消释放。
- 渠道密钥加密、独立用户 Key 限额、成本倍率快照、用户数据投影不含内部成本。
- 模拟上游成功、失败、结果不明确、人工核对和并发绑定；未知请求不自动再次生成。
- 两个用户同时争用渠道预算，只允许符合预算的请求进入。
- 批次循环和依赖拒绝、幂等执行、输入归一化与恢复路径。
- 图片上传、UTF-8 中文文件名、BMP 解码、签名 URL、缩略图、图像派生、提醒、到期、ZIP 与永久清理。
- 已保存结果在上游过期后的恢复、已过期交付在核对费用后正确终止。
- 验证码五次失败上限和不可复用；管理员敏感操作要求近期密码验证；SSRF 私有地址拒绝。
- 个人和后台资金流水分页、固定数据集顺序与完整性；未全部加载时标注搜索与导出范围。
- Edge 内创建用户、手工充值、用户流水、价格折扣预览、测试渠道、站内 Key、上传素材、画布报价/提交/取消。
- Edge 内七种生成模式、延长固定 adaptive、快速离开保存、慢网络连续编辑后重开、离线仅名称恢复、退出后身份切换。
- Edge 内保存完成后重载不出现错误草稿提示；手机节点点击、参数面板展开/收起与页面无横向溢出。
